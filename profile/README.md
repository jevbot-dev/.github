## Jevbot

挂在你正在用的 App 旁边的判断层：读懂屏幕上正在发生什么，用 [TypeSafe Jev](https://typesafe.ai/) 判断模型给出带把握度的结论，再把结论变成可以一键执行的动作。

第一个跑通的场景是聊天副驾——对方发来一句话，面板立刻告诉你**这句话真正想要什么、风险几级、该怎么回**，并给出 3 条候选回复。点「填入」进输入框，**发送永远你自己按**。
